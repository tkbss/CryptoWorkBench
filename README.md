# CryptoWorkBench

Binary file MAC containers are available through
`PATH container = MacPack(p,k,source)` and
`VAL valid = MacVerify(p,k,container)` with PARAM, KEY and PATH references.
See [CWM format and independent verification](CryptoScript/InfoDocs/Info.Func.MacPack.md),
[verification behavior](CryptoScript/InfoDocs/Info.Func.MacVerify.md) and the
[F04 implementation report](docs/F04-implementation-report.md).
