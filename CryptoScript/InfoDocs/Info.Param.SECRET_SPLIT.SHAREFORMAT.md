# #SHAREFORMAT for SECRET_SPLIT

Optional quoted X-Y (default), Y-X or SEPARATE-X. X-Y prefixes the payload with one index byte; Y-X appends it; SEPARATE-X uses repeated integer/HEX argument pairs. This changes external representation only. Other literals cause syntax errors and programmatic values are validated.

See [SECRET_SPLIT](cryptoscript-info://mechanism/SECRET_SPLIT), [Secret import examples](cryptoscript-info://function/Secret) and [complete Print output](cryptoscript-info://type/SECRET).
