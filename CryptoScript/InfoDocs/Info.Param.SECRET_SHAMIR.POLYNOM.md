# #POLYNOM for SECRET_SHAMIR

Optional only for SECRET_SHAMIR. Quoted SHAMIR-GF256-11B (default) or SHAMIR-GF256-11D. This selects the reduction polynomial of GF(256), not a key algorithm and not the random sharing polynomial. Other literals cause syntax errors; programmatic parameter objects are also validated.

See [SECRET_SHAMIR](cryptoscript-info://mechanism/SECRET_SHAMIR), [Secret import examples](cryptoscript-info://function/Secret) and [complete Print output](cryptoscript-info://type/SECRET).
