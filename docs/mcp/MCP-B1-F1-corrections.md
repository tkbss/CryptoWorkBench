## Causes and restored invariants

**Registration and selection have different lifetimes.** The bridge checks each registered editor's live document during attachment and publishes the open-registration count independently of the selected view. Attach and activate share transition checks and registration selection. Closing retires an association when its obligations permit, checking that the retiring coordinator still owns the association. A drain certificate belongs to one transition, including the transition with no document. Stopping prevents fresh native admission and reactivation. Existing identity, mutation and interpreter leases retain their roles.

**A callback can invalidate a previously correct check.** A native Return captures its line, text, full caret, selection, editor lifecycle and original ticket before invoking popup callbacks. It checks again after diagnostics publication, immediately before the execution handoff. The completion request separately validates its own session, range, editor, document version, caret and provider after writability callbacks and inside the native group. Acceptance bookkeeping requires a live session. The public GUI text-execution entry rejects fresh work from a controlled observer after authorized replay lookup and before reservation.

**Search and clipboard commits need concrete write targets.** Replace All captures the search options, replacement and descending offsets. It checks complete writable coverage, revalidates under active admission, then opens one native group and applies that exact plan. A panel change during the group's UpdateStarted cannot select new ranges. An identical Replace Next uses native search navigation without opening a document update. Clipboard admission captures the full caret position and original native selection, including rectangular endpoints. After the platform wait it obtains the provider's answers for those segments, validates the input again, and supplies those answers to the native selection operation. Extensible provider callbacks finish before insertion. Its temporary provider is restored in finally only if still owned by the operation.

**Displayed values need both a target identity and a binding lifetime.** A detached model carries a weak identity for its original interpreter declaration. Under the interpreter reservation, the commit compares that identity with the live dictionary entry before entering the mutation/version-advance block. A parameter value edit uses its captured key. The grid presents the name as read-only and the command rejects a modified key supplied programmatically. A view-binding/publication stamp prevents an interrupted publication from refreshing an invalidated map. The Markdown view retires its command token at detach and installs a fresh token upon legitimate reattachment.
